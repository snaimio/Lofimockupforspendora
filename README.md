## 📌 Technical Overview

This repository represents the initial structural wireframing and user experience architecture for the **Spendora** platform. Developed in tandem with Figma low-fidelity specifications, it implements layout ergonomics, navigation pathways, and user interaction mechanics prior to visual high-fidelity skinning.

---

## ✨ Key UX Workflows

- **📐 Information Hierarchy**: Rapid prototyping of screen layouts, subscription catalogs, and spend summary blocks.
- **🧭 Navigation Flow**: Low-friction user journeys between active subscriptions, upcoming payments, and budget settings.
- **📱 Responsive Component Ergonomics**: Wireframe testing for cross-device mobile and web layouts.

---

## 🛠️ Stack & Prototyping Tools

- **Framework**: React 18 & TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS & Radix UI primitives
- **Figma Design**: [Spendora Lo-Fi Wireframes Canvas](https://www.figma.com/design/04AF6KU0tIIt8jW1EqLrzK/Lo-Fi-Mockup-for-Spendora)

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)

### Steps
```bash
# Clone the repository
git clone https://github.com/snaimio/lo-fi-mockup-spendora.git
cd lo-fi-mockup-spendora

# Install dependencies
npm install

# Run local development server
npm run dev
```
